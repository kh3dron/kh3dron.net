4.0 Revising

Edit css/hosted/industrial.css, bump the REV comment on line 2, commit, push to main. GitHub Actions redeploys; every consumer picks the change up within 600s. No consumer repo is touched.

Bump the REV row in section 1.0 to match. A revision that is not recorded here is a revision that cannot be identified from a rendered page.

4.1 Pinning

industrial.css is a rolling file: it always serves the current revision, and a change to it changes every consumer. There are no pinned copies, because a second copy of the same CSS is the drift this arrangement exists to remove.

If one consumer must freeze, copy the current file to industrial-<rev>.css, link that from the frozen site only, and add a row for it in section 1.0 marked FROZEN. Accept that it will not receive further edits.

4.2 Verify after deploy

curl -sSI https://kh3dron.net/css/hosted/industrial.css | grep -E 'HTTP|content-type|cache-control'

Expect HTTP/2 200 and content-type: text/css. Anything else means consumers are rendering unstyled.

5.0 Consumers

Sites linking a stylesheet from this directory. Kept current by hand — an unlisted consumer is a site that will break silently on a bad edit.
